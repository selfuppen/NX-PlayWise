## 阶段记录与临时产物

阶段材料只供对应任务查阅，不是全局开发或测试的前置阅读。2026-10的1952迁移、去1440代理及真机验证汇总见[当前进度与后续指导](当前进度与后续指导.md)，其现场和后续安排仅在该阶段范围内有效。全局指南移出的旧阶段描述保存在[阶段信息摘录](验收记录/2026-10/全局指南阶段信息摘录-20261016.md)，仅供追溯。

[验收记录](验收记录/README.md)按月份和主题归档计划、候选冻结、失败／恢复、机器结果及人工复核。它们需要保存以追溯当时事实，不能视为随手可删的临时文件，也不能直接照旧脚本重放。

`device-reports/` 的原始附件未随Markdown提交，须另行保留。未封存的本地草稿、构建中间物和可再生缓存属于临时产物；清理前先检查是否被报告索引引用。具体迁移及保留规则见[目录整理说明](目录整理说明.md)。
