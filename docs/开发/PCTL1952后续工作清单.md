## 统一验证方式：集中准备，减少值守

本节同时适用于 P1、P3 和 P4；按验证目标选择必要场景，不要求每批重复休眠、重启或所有旧实验。代理承担准备、连续采集、拉回、机器断言和离线报告；用户只承担稳定接口无法替代的实体操作及真实画面确认，不需要持续盯日志或逐条回复。

| 执行段 | 代理负责 | 人员介入与完成条件 |
| --- | --- | --- |
| A：离线准备 | 列已证明项/缺口/通过标准，核对采集字段与实际二进制，完成构建、前像、恢复材料、目录、租期和失败条件；生成本批操作清单 | 尚不请求重启；准备和回读齐备才进入 B |
| B：一批实体操作 | 发一次明确操作单，列顺序、持续时间、阶段标记和异常停止条件；必要时核对正常新 boot | 按本批需要完成正常启动、真休眠/唤醒、底座拔插、PIN/长按等一组操作，统一回复；不安排已知故障绕行 |
| C：有界无人值守采集 | 在已有授权范围内低频读取/拉回原始材料；按预先确定的规则操作只提交一次；满足设备端点时长和样本条件后结束 | 无需盯日志；真休眠窗口不发 status/控制请求；fatal 或未知写入时停止依赖操作并核对现场 |
| D：离线核验与集中复核 | 哈希、boot/日期/tick、各 Result、带符号余额、实际授权及恢复检查；生成规范化样本、汇总和带时间/阶段/哈希的 HTML 图集 | 一次确认必须的可见性、真实恢复/运行效果等观察，另存人工记录；缺失项不填 true |
| E：恢复与封存 | 按本批前像核验规则、完整 0x44/timer、启动项、NSP、runtime 和停采；归档本批材料，离线重跑报告 | 仅在当前进程尚未加载已恢复原像等必要情形安排一次收尾正常启动；记录恢复完成或待处理 |

每个危险窗口仍执行原有恢复期限和事务；将画面复核与材料封存集中到 D/E，不代表让限制或诊断写入一直等待人员收尾。

- [ ] **P3-1 写出新策略与证据缺口**：区分“1952 可读”与“取消代理后配置/计时/恢复安全”。以本地协议、固定源码和真机证据调查，不根据 libnx 缺少私有封装推断 raw layout。
- [ ] **P3-2 按稳定方法证明无代理生命周期**：先完成新候选 A/B 批次准备，再有界采集真正不限时 → BLOCKED → 不限时的累计、timer、自动解除无 1451 与健康规则组合，画面在 D 集中确认，0x44/timer 在各窗口及 E 精确恢复；不把旧代理短链或旧旁路样本移用到此候选。
- [ ] **P3-3 实现新契约及门禁**：小步修改策略，新增成功与失败回归，同步协议与候选验收文档。当前 `pctl1952_v1_proxy1440` 门禁明确拒绝去代理契约，不能更换字符串后借用旧通过报告。
- [ ] **P3-4 独立完整验证**：统一构建含 Eden、新冻结包、新样本和新报告全部通过后，才能声明代理移除；任何不可解释变化保留失败证据，继续使用已验证的代理基线。

## 每项工作的记录方式

执行时在批次记录中填写下表，完成后再更新本清单勾选状态；不在正在运行的构建中编辑 tracked 文档。计划日期不能代替实际完成时间。

| 字段 | 填写内容 |
| --- | --- |
| 任务 ID / 状态 | 如 P1-2；未开始、进行中、阻断、通过或失败 |
| 操作者 / 实际时间 | 采集与签署分别记录 |
| 候选 / 环境 | 完整 commit、release ID、Zip/组件哈希；机型、HOS、Atmosphère |
| 实际命令 / 退出码 | 构建、采集、校验、晋级分别保留日志路径 |
| 批次 / 人员操作 | A–E 执行段、采集租期/结束条件、最少实体操作清单、实际操作时间与一次复核记录 |
| 证据 / 恢复 | 报告、raw、规范化样本、截图及哈希；0x44/timer 恢复结果 |
| 偏差 / 未覆盖 | 不能解释的变化、缺失事实、独立资格限制 |
| 下一步 | 修复、补采、重新构建新候选或执行下一任务 |

若候选身份、组件或附件字节变化，停止沿用旧验证记录并重新核验；若需要修改源码，先回到 P0。新增功能任务再遵循[开发指南](开发指南.md)、[协议](../设计/协议.md)及[视觉风格与设计指南](../设计/视觉风格与设计指南.md)，不要顺带重写无关功能。
