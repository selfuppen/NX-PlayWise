# 运行资源优化与等价回归

2026-11-09，Asia/Shanghai。完成常驻后台、NRO 与 Overlay 的内部资源优化；完整 Host C／Python／UI 门禁、标准分发包及 Eden NRO 构建／校验通过。优化前后 6,870 张固定输入预览的 SHA-256 全部相同。没有部署、发布、提交或执行真机性能对比；Eden 模拟器场景按日常策略未执行。

## 实现与兼容边界

- 后台将规则／状态的 6,144＋4,096 字节 JSON 常驻缓存替换为解析结构体。保持每次文件元数据检查与已有失效入口；缓存未命中先失效，读取／解析失败不能返回旧成功状态。保存成功后解析实际序列化文本，保存失败不发布候选值；删除恢复原有缺省行为，空文件仍报错。
- 规则缓存不保留日历指针。每次使用仍加载并验证当前日历、绑定实际运行对象；日历校验与构造合并为一轮，所有选中年份都校验，只有相邻三年留作查询。远年损坏同样失败并清空输出，没有跨轮询缓存。
- NRO 字形缓存命中直接复用位图与度量；需要字体处理的未命中才设置字号。阴影先裁剪，再按扫描行跳过必然属于实心卡片内部的区间，边缘继续使用原距离、透明度与混色公式。
- Overlay 共用行遍历器，以增量字宽取代反复测量整行前缀。高度只计数、绘制直接消费行范围和宽度；固定按钮只保留可见行，仍按原规则缩字号、居中和添加末行省略。
- 故障注入发现原 NRO 位图分配失败会把空白字形永久缓存。本次保留失败当帧的 advance，不占用成功缓存槽，后续测量／绘制重试并恢复位图。正常预览像素保持一致。

后台唤醒、队列扫描、PCTL 新鲜度、输入采样和占用保护没有改动。帧率、焦点呼吸、主题渐变、弹层动画与 CPU 渲染方式保持；没有新增整屏缓存、线程或生产高频统计。IPC、请求／回执、持久化格式及错误码保持；vendored libtesla 没有改动。

缓存净减少 **9,720 字节**，超过 8 KiB 门禁。1,000 次已预热的 NRO 测量在交替字号时，字体设字号和字体加载均为 **0 次**。阴影距离计算减少 77.7%；Overlay 测量字节减少 93.6%，长词与中文测试也遵守每个字节最多测量两次的线性上界。这里的分配字节是累计申请量，不是峰值或进程 RSS。

| Overlay 高度 | 162.068／207.279／264.506 ms | 9.412／13.439／24.327 ms |
