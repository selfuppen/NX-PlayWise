### 进入条件与现场前像

重启确认后先核对用户描述的故障及恢复效果，再只读采集：设备地址、机型、HOS/AMS、源 boot/PID/release、runtime 与全部 SD 安装成员、当前前台、fatal/crash 清单、请求队列、交接/恢复事务、启动标记、公共规则、当天状态、完整 0x44/timer、1952 和带符号1454。家庭 PIN 与密钥不写入本文件、命令、日志或画廊。

前像未完整、设备新增 fatal、原控制结果未知、恢复未证实或输入通道异常时停止依赖操作。已核实的健康原进程优先复用；候选不同时按正常 PIN 的安全交接更新。同候选采集已停止时使用显式用途的安全重启前检，不伪造 release，不强杀后台。自动工具的 forwarder 与不限时等条件不满足时先登记具体缺口，核对已验证替代路径；不默认要求再重启整机。

恢复材料分为设备不可变安装前像和业务规则前像，实际读取后各自独立封存并核验。本地冻结候选只能用于安装目标，不能充当设备当前安装的原像。工具没有通用自动回滚命令；旧文件已恢复到 SD 与旧进程已实际加载分别报告。

### 本地准备的有界预算

标准采集离线准备为 5400 秒，5 秒采样，连续读取或保存失败上限各 3；租期从实际后台初始化起算。预计导航/交接 480 秒、NRO 页面 900 秒、Overlay 四态及逐段恢复 1800 秒、手机闭环 600 秒、最终恢复/停采 600 秒、余量 1020 秒，总计 5400 秒。激活前用实际设备日期确认距午夜不少于 5460 秒；不足则缩小本批窗口或另排，不能改时钟或运行中续租。

UI 来源取证必须在交接完成后用实际 boot 和新鲜标准样本生成。每个前端窗口最多 900 秒、128 条，并正常重开 NRO 或退出旧 Overlay 模块再加载；仅隐藏再显示不算加载。没有新 boot/tick 时不生成可激活配置。

输入批次沿用 `bounded_input_batch.py` 的原身份、期限、动作数、采样与失败收尾。每个窗口先核对导航，再固定动作上限与恢复截止；额度/护眼/就寝窗口优先控制在 300 秒以内（自然边界需要更长时另算）。只用 pixelPeek 取图，不为截图初始化输入。游戏只用本批核实的一个非关键游戏，不重走旧第二游戏/HID故障路线。
