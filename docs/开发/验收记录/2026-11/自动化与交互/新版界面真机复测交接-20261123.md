## 重启后的进入条件

用户确认重启完成后，先做新批次只读核对。记录设备、HOS/Atmosphère、boot/PID、runtime/SD 清单、前台、近期 fatal/crash、队列、交接/恢复事务、启动标记、规则、当天状态、完整 0x44/timer 和带符号余额。原报告中的 IP、PIN、快捷键、forwarder、PID 和 boot 都属于历史线索，操作前必须重新核对。

旧记录曾使用 OLED、HOS 22.5.0、Atmosphère 1.11.2，涉及 HID 资源异常。历史有潜水员戴夫与 Woodo，曾缺实体底座。当前故障细节与恢复状态未重新取证。新对话应先收集用户对本次故障与重启结果的说明，再决定输入与部署条件。设备 fatal、未知写入或恢复未证实时停止依赖操作。

阅读[无人值守更新指南](../../../无人值守更新与测试指南.md)和[稳定探测方法](../../../真机稳定探测方法.md)。优先复用安全交接，从实际核实的 NRO 孩子页、无弹窗、无 Overlay 的入口更新。核对当前 candidate 与 runtime 是否一致、同候选门禁、当天限制及恢复状态，按现有工具能力选择适用路径。若 forwarder 前提不满足，核对仓库已验证 applet 安装与交接事务及原证据。不得直接重放阶段脚本。
