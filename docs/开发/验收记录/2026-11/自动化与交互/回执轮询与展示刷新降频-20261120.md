# 回执轮询与展示刷新降频（2026-11-20）

本批基于 `c516733d` 继续审查性能与SD交互。开始时发布准备记录已有用户修改，本批保留。用户接受适度降低展示新鲜度，并授权按需真机测试；本批选择能由确定性Host验证的客户端等待与展示偏好优化，不修改家长规则或部署到设备，不进行底座测试。

## 改动与边界

1. 普通SD回执从固定100ms改为100／200／400／800／1000ms退避，首次响应窗口保留100ms，持续等待最多每秒一次。原请求只提交一次；IPC正常事件立即取回，受理未知或失联仍只查原ID，不重发。30秒超时不延长。
2. NRO和Overlay中断兑换恢复共用有状态的只读核对器，首次立即查盘，随后退避到1000ms。失败、坏回执和未知结果都降频，切换ID或单调回退立即重新核对；继续保留未决兑换，不能重新消费或伪造结果。
3. 浮窗普通翻页不再超过5秒就发status，复用既有未满30秒的有效快照；缺失／过期／原不可用条件仍刷新，Y、顶部刷新、重开、归零复查及动作门禁不变。减少重复status也减少其队列、回执和审计工作，具体物理SD收益未测。
4. 开启原因通知时，后台通知偏好定时重读从1秒改为5秒；关闭时仍为5秒。收到IPC通知时立即读回，但不是所有偏好保存入口都会发通知；应用内保存或外部直接改文件均可能等到下一次定时重读，最长一个间隔另加调度／I/O耗时。读取或解析失败仍按关闭。只改变展示偏好读取，不改控制规则、受限观察、通知ACK、ready租约或输入所有权。

未采纳跨轮PCTL缓存、延长ready租约、减慢控制期限或隐藏快捷键扫描。未把资源调用次数换算为省电百分比。无需为这些变更启动真实危险窗口。
