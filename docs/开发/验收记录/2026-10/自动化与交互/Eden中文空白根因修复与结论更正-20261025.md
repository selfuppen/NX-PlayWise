# Eden中文空白根因修复与结论更正（2026-10-25）

用户指出`F:/Eden-MCP-Chinese`原安装已解决中文显示，而自动测试中应用内中文空白。核对证实是shared执行器引入的固件访问错误，不能把它归因于源安装未修好或模拟器必然缺少CJK字体。此前[日历／就寝记录](Eden地区日历与就寝分区端到端-20261025.md)中的环境解释由本补充记录更正，旧raw、截图、manifest和封存脚本不改写。

## 根因与可复核证据

2026-10-25只读核对源安装及受管缓存：

| 项目 | 原安装 | 旧shared缓存 |
| --- | --- | --- |
| 路径 | `F:/Eden-MCP-Chinese/user/nand/system/Contents/registered` | `D:/PlayWise-Eden/shared-resources/firmware/Contents/registered` |
| NCA文件 | 238 | 238 |
| 与来源逐文件SHA-256 | 基准 | 全部相同，非同一硬链接 |
| Windows只读属性 | 0份 | 238份 |
| 不写内容的r+b打开 | 成功 | PermissionError 13 |

旧`eden_runtime.py`在首次缓存复制后将所有文件`IsReadOnly=true`。Eden用读写模式打开安装NCA，即使只是读取固件/字体，Windows只读属性也导致权限拒绝。旧原生日志显示NCA以mode=3打开失败并`permission denied`，随后`FontChineseSimple`等回退`SynthesizeSystemArchive`。缓存内容哈希相同、exe相同和配置语言相同，都未能检测这类访问能力差异。

`device-reports/eden-fonts/20261025-investigation/before.json`保存迁移前238份文件属性、来源／缓存哈希、非同一文件断言、历史日志哈希及错误计数。此前shared main/support/web各一批，以及plans四批的最终原生日志，每份均有476条NCA权限错误。源安装没有同类只读属性；实际exe SHA-256仍为`e81f589674c9db34d4c335427e70d3d5b93ed74bef0debf8079a2975d02c6986`。

## 修复

本次仅修改Python执行器、Host测试及文档，没有修改C/NRO、Eden程序、源安装配置、密钥或源固件。

- 共享固件不再设置OS文件只读。持有本批独占租约、核对来源内容哈希后，只在受管缓存移除旧只读属性。逐文件r+b打开并立即关闭，不写任何NCA内容，前后复核完整哈希，保存`firmware-access.json`。
- 不以ACL放宽、重装固件或每批复制340MB固件绕行。仍共享同一缓存，来源／缓存内容前后哈希门禁保留；缓存若发生实际字节变化，收尾拒绝通过。
- 新启动同时核对实际ConfigDir/NANDDir/SDMCDir。首份完成帧后，业务输入和截图前归档原生日志；出现NCA权限拒绝或必需标准／简体／繁体字体的合成回退立即停止。每PID的原始日志与摘要纳入`native_environment_version:1`及离线核验。
- 删除plans首次设置后强制英文切换。沿用源系统语言index 15、地区4、GLASM；私有时区显式34。NRO保持“跟随系统”。

Host测试覆盖只读缓存r+b失败→清除缓存属性后成功、内容不写入、缓存篡改拒绝、NCA权限／字体回退拒绝、NAND路径不匹配拒绝，以及原有联接、租约、清理和输入门禁。

## 对旧结论的影响

1. **中文视觉结论必须撤回／限定。** 中文空白时不能证明中文文案、提示、宽度测量和布局可读。历史材料中“中文起点/中文回归”若仅依据语言配置，也不能据此认定视觉通过。
2. **旧环境与源安装等价的说法不成立。** 所有NCA访问被拒绝不只涉及字形，系统归档和服务也可能回退。旧main17/support6/web5及plans成绩保留为原降级环境下的结果，不直接签给修复后的固件环境。
3. **回执与文件数值断言不因缺字自动变成伪造或失败。** 它们仍证明当时同ID请求、模拟业务及持久化的实际结果，但不能超出该环境范围。中文提示可见性也不能由这些数值替代。
4. **本批中文X01/X04由重新实测恢复结论。** 同一NRO在正常固件访问环境中重新7/7通过。main/support/web整套本批未重复，不能补签为修复环境全部通过。
5. 第三批历史重开UI/HID进度停止根因仍未确定。不能用这次中文恢复或一次健康重开宣称稳定性问题已解决；真实PCTL、Overlay、睡眠、底座和生产资格仍独立。
