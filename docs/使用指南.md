# 使用指南

本指南介绍如何安装和使用任我玩 · PlayWise。当前公开版本为 `0.1.3`，已在 Nintendo Switch OLED、HOS 22.5.0 和 Atmosphère 1.11.2 环境完成资格验证；它利用系统家长控制功能完成游玩额度管理、系统计时和到期提醒。

## 安装前准备

你需要：

- 一台已安装 Atmosphère 和 Homebrew Menu 的 Nintendo Switch；
- 与当前版本匹配的 PlayWise 安装包；
- 一张可在电脑上读写的 Switch SD 卡；
- 当家长控制已经限制启动程序使用时，需要打开 PlayWise Overlay，必须单独安装 [Ultrahand Overlay](https://github.com/ppkantorski/Ultrahand-Overlay) 或者其它 Tesla overlay 工具。

![Ultrahand 的 Overlay 列表中选中 PlayWise / pctc.ovl](images/usage/09-ultrahand-overlay.jpg)

PlayWise 安装包不会安装或修改 Overlay 管理器。可参考(推荐使用)[大气层包安装与使用说明](https://docs.qq.com/doc/DVW9PVE5sU0FEd0tP)准备相关环境。本人是在用整合包测试的，强烈推荐。

## 全新安装

1. 完全关闭 Switch，并取出 SD 卡。
2. 解压 PlayWise 安装包。解压目录顶层应包含 `atmosphere` 和 `switch` 两个文件夹。
3. 把这两个文件夹复制到 SD 卡根目录；系统询问时选择合并文件夹。
4. 安全弹出 SD 卡，插回 Switch 并重启机器。
5. 进入 Homebrew Menu(相册)，打开“任我玩”。

![安装包与 SD 卡根目录的合并位置](images/usage/01-install-sd-root.jpg)

![Homebrew Menu 中的“任我玩”入口](images/usage/02-launch-playwise.jpg)

## 软件入口说明

PlayWise 提供 Companion NRO 和 Overlay 两个入口，可按当前场景选择：

| 入口 | 适用场景 | 主要功能 |
| --- | --- | --- |
| Companion NRO | 日常使用的完整入口 | 直接进入小孩区，可提前兑换加时码；输入 PIN 后进入家长区，可设置额度、管理周计划以及生成或兑换加时码。 |
| Overlay | 已被限制启动其他程序或正在游戏时的快速入口 | 可尝试直接输入加时码恢复可玩时间，不提供完整的家长管理功能。 |

平时优先从 Homebrew Menu 打开 Companion NRO；无法启动其他程序或不方便退出游戏时，再通过 Overlay 快速兑换加时码。

## 升级现有安装

升级时不要直接覆盖已有的 `switch/playwise` 数据目录，否则可能丢失 PIN、密钥、规则或状态。Windows 用户应使用与安装包版本匹配的 `tools/install_package_to_sd.ps1`：

1. 关闭 Switch，取出 SD 卡并连接电脑。
2. 解压新版安装包。
3. 在 PowerShell 中进入安装脚本所在的仓库目录，把 `<解压目录>` 和 `E:` 换成实际路径及 SD 卡盘符：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install_package_to_sd.ps1 -SourceFolder <解压目录> -Drive E: -Apply
```

4. 按提示核对目标路径，并输入显示的 SD 卡盘符确认。
5. 完成后安全弹出 SD 卡，再插回 Switch 并重启机器。

普通升级不要使用 `-Clean` 或 `-Full`，这两个选项会清空 PlayWise 数据。macOS 或 Linux 目前没有等价的安全升级脚本；请先完整备份 SD 卡中的 `switch/playwise`，再手动升级。

## 首次设置

第一次打开“任我玩”时，按照向导完成四步设置：

1. **设置家长区快捷键**：固定的 `Minus -` 入口始终可用，也可以增加自定义按键组合。
    ![首次设置家长区快捷键](images/usage/03-1-set-key.jpg)
2. **设置 PlayWise PIN**：用于保护本应用的家长区和安全设置，它不是 Nintendo 官方家长控制 PIN。
    ![首次设置 PlayWise PIN](images/usage/03-2-set-pin.jpg)
3. **确认接管系统控制**：PlayWise 会先检查当前环境，通过后才应用设置。
    ![首次设置确认接管系统控制](images/usage/03-3-confirm-control.jpg)
4. **选择进入区域**：进入家长区继续配置额度，或进入孩子区查看和兑换加时码。
    ![首次设置选择进入区域](images/usage/03-4-choose-area.jpg)

设置中途退出不会从头开始，下次打开会继续未完成的步骤。若提示“兼容性待确认”，请阅读页面说明并由家长确认；若提示“保护模式”，请到“支持与恢复”按页面推荐操作处理。

  ![今日额度](images/usage/04-1-todays-quota.jpg)

  ![周计划编辑页面](images/usage/04-2-weekly-plan.jpg)

  ![加时码与安全](images/usage/04-3-add-time-code-and-security.jpg)
- **支持与恢复**：处理保护模式、紧急停用、诊断导出和恢复操作。
  ![支持与恢复](images/usage/04-4-support-and-recovery.jpg)

## 生成和兑换加时码

### 生成加时码

#### 直接在 Switch 生成

1. 进入“家长区 → 加时码与安全 → 立即生成加时码”。
2. 选择需要增加的分钟数并生成 8 位码。
3. 把代码交给孩子，在 Companion NRO 或 PlayWise Overlay 中输入。
4. 核对兑换后的预计时间，确认后完成兑换。

生成代码不会立刻修改额度；代码只在成功兑换后使用一次。同一天生成的新代码不会自动撤销之前生成的代码。
![Switch 生成加时码](images/usage/08-switch-generate-code.jpg)

#### 使用手机或电脑生成

##### 扫码快捷打开网页，导入本机配置生成

1. 在 Switch 打开“家长区 → 加时码与安全 → 手机/电脑生成加时码”。
2. 验证 PIN 后，用可信的家长设备扫描二维码。
3. 在网页确认设备，选择 UTC+8 生效日期和分钟数，生成 8 位码。
4. 在 Companion NRO 或 Overlay 中输入并确认兑换。

##### 离线导入配置生成

无法扫码时，可在“加时码生成管理”中导出 `parent-import.json`，把文件传到家长设备，再在 PWA 中依次选择“导入配置文件”和“导入此设备”。二维码和配置文件都包含生成加时码的权限，请勿分享给他人。

![Switch 上的二维码配对页面](images/usage/06-pairing-qr.jpg)

### 兑换(使用)加时码

#### Overlay 上兑换

##### 通过 Ultrahand 打开 Overlay

1. 当家长控制已经限制启动程序使用，或其他需要快速加时的界面，使用你在 Atmosphère/Ultrahand 中设置的快捷键打开 Ultrahand。
2. 进入 **Overlay** 列表，选择 PlayWise（文件名为 `pctc.ovl`）。
3. 按 `A` 加载 Overlay；看到顶部标题“自律约定 / 兑换加时奖励”后，即可开始输入加时码。
4. 使用 `B` 可关闭 PlayWise Overlay，返回游戏。

![Ultrahand 的 Overlay 列表中选中 PlayWise / pctc.ovl](images/usage/09-ultrahand-overlay.jpg)

##### 在 Overlay 中输入和兑换加时码

1. 用方向键或左摇杆移动数字高亮，按 `A` 输入当前数字；也可以直接点按屏幕上的数字键。
2. 重复输入 8 位数字，顶部输入槽会显示已输入的位数。
3. 输错时按 `X` 删除最后一位；按 `Y` 清空后重新输入。
4. 输入满 8 位后，按 `+` 或点按“提交加时奖励”。
5. 先检查预览中的“兑换前”和“兑换后预计还能玩”，再按 `A` 或 `+` 确认。若兑换后将没有可玩时间、状态未知或会从不限时变为限时，必须长按手柄 `A` 确认；触屏不能跳过这个确认。
6. 看到“加时成功”后，按 `A`、`B` 或 `+`，也可以点按页面关闭结果；若取消、预览失败或提交失败，代码不会被消费，可以重新输入。

`Y` 在未输入代码时用于刷新状态；`-`、`L` 或 `R` 可展开/收起状态详情。Overlay 会先显示预览，确认后才正式兑换，不要在“结果确认中”时重复提交同一枚代码。

## 家长端 PWA

公开演示网页位于：[https://selfuppen.github.io/NX-PlayWise/](https://selfuppen.github.io/NX-PlayWise/) 。

![家长端 PWA](images/usage/11-parent-pwa.jpg)

页面使用浏览器 Web Crypto 在本地生成加时码，不会把设备 ID、密钥、日期或代码提交给业务后端。配对信息会保存在当前浏览器的本地存储中，因此只应在可信的家长设备上使用。

### 中国大陆访问说明

公开演示网页托管在 GitHub Pages。中国大陆网络环境下可能无法访问或加载不稳定，可能需要使用能够访问 GitHub Pages 的网络环境。如果不方便使用该网页，可以在电脑上本地运行 PWA。

### 在电脑上本地运行 PWA

本地运行适合在同一台电脑上生成加时码，不需要服务器或前端构建工具。

1. 从[项目仓库](https://github.com/selfuppen/NX-PlayWise)下载源码压缩包并解压。熟悉 Git 的用户也可以运行：

```text
git clone https://github.com/selfuppen/NX-PlayWise.git
cd NX-PlayWise
```

2. 在仓库根目录启动本地服务。

Windows：

```powershell
py .\tools\ptc_frontend_server.py
```

![Windows 终端启动本地服务](images/usage/12-windows-local-server.jpg)
如果没有 `py` 命令，可把它换成 `python`。

macOS 或 Linux：

```sh
python3 tools/ptc_frontend_server.py
```

3. 保持终端窗口运行，并在同一台电脑的浏览器打开：

```text
http://127.0.0.1:8765/
```

![Windows 浏览器打开 localhost](images/usage/13-windows-pwa-localhost.jpg)

4. 从 Switch 导出 `sdmc:/switch/playwise/parent-import.json`，复制到电脑；在本地页面中选择“导入配置文件”，再选择“导入此设备”。

![Windows 导入配置文件](images/usage/14-windows-pwa-import.jpg)

5. 选择日期和分钟数，即可生成 8 位码。

不要直接双击 `index.html`。PWA 需要通过 HTTPS 或 `localhost`/`127.0.0.1` 打开，浏览器才能使用 Web Crypto 和离线缓存。从公开网页切换到本地地址后，需要重新导入设备，因为两个地址的浏览器存储互不相通。

### 部署给手机扫码使用

`localhost` 只代表当前设备：手机扫描指向 `localhost` 的二维码时，会访问手机自身，而不是电脑。普通的局域网 HTTP 地址通常也不满足浏览器的 Web Crypto 安全要求。

如需手机直接扫码配对：

1. 把仓库中的 `tools/ptc_frontend` **完整目录内容**上传到你信任的 HTTPS 静态站点。它是纯静态 PWA，无需 `npm`、无需构建、无需后端，可部署在域名根目录或子路径。
2. 用手机打开部署后的根地址，确认页面能正常加载。
3. 在 Switch 进入“加时码与安全 → 加时码生成管理 → 编辑二维码跳转地址”。
4. 填写部署后的完整 HTTPS 根地址，建议以 `/` 结尾。
5. 返回“手机/电脑生成加时码”，重新显示二维码并扫码配对。

自定义站点可以读取二维码中的设备名和加时码密钥，只能使用自己信任的部署地址。Switch 只检查地址格式，不会验证网页是否为完整、兼容的 PlayWise PWA。

## 常见问题

- **找不到“任我玩”**：检查 SD 卡上是否存在 `switch/playwise/pctc.nro`，并确认从 Homebrew Menu 打开。
- **找不到 Overlay**：确认已安装 Ultrahand Overlay，并检查 `switch/.overlays/pctc.ovl` 是否存在。
- **加时码无效或已使用**：核对配对设备、UTC+8 日期和密钥；修改密钥后，需要重新配对并生成新代码。
- **一直显示“正在同步”或错误码 `306`**：先在“系统设置 → 家长控制”中开启家长控制，返回 PlayWise 后重新检测。
- **显示“保护模式”或“控制已停用”**：进入家长区的“支持与恢复”，执行页面显示的推荐操作；不要直接编辑或删除数据文件绕过检查。

需要提交问题时，可先在“支持与恢复”导出诊断包。诊断包不会包含 PIN、加时码密钥或完整离线码。项目 Issue 地址为 [https://github.com/selfuppen/NX-PlayWise/issues](https://github.com/selfuppen/NX-PlayWise/issues)。
