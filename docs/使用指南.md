# 使用指南

本指南面向在已安装自定义固件的 Nintendo Switch 上使用“任我玩 · PlayWise”的家长和孩子。首次安装建议使用完整交付包；家长用手机或电脑生成加时码时，推荐先按下文联网扫码配对。

> [!IMPORTANT]
> PlayWise 依赖 Nintendo 官方家长控制的“主机使用时间”计时和“时间到了暂停软件”。HOME、系统设置等亮屏使用也可能消耗额度。请在安装前用没有未保存进度的游戏验证：官方额度会累计，开启暂停开关后到时确实阻断软件。PlayWise 不会替你修改官方开关，也不能修复底层计时故障。

> [!WARNING]
> 每日额度耗尽或就寝限制生效后，游戏、Homebrew、HOME、系统设置和 PlayWise 主机应用可能被 Nintendo 原生弹窗阻断。PlayWise 侧的主机内操作入口是游戏内浮窗；请在设置低额度前装好并试用浮窗。Nintendo 原生弹窗仍可用官方 PIN 临时解锁；这与 PlayWise PIN 是两套不同的授权。

## 安装

### 准备与全新安装

需要一台运行 Atmosphère 和 Homebrew Menu 的 Switch、一张可在电脑上读写的 SD 卡，以及单独安装的 Ultrahand 或其他 Tesla 浮窗管理器。PlayWise 安装包包含 PlayWise 浮窗文件，但不包含浮窗管理器。

1. 先完成上面的 Nintendo 官方家长控制验证，再备份 SD 卡中已有的 PlayWise 数据。
2. 首次使用优先解压 `playwise-complete-<版本>.zip`。它包含标准 Switch 安装包 `playwise-<版本>.zip` 和家长用的 `playwise-offline.html`。
3. 关闭 Switch，取出 SD 卡；解压标准包，确认顶层为 `atmosphere` 和 `switch` 两个目录。将它们合并到 SD 卡根目录，遇到同名程序文件时覆盖。
4. 安全弹出 SD 卡，装回 Switch 并重启。进入 Homebrew Menu 打开“任我玩”，完成下节向导。
5. 用已安装的浮窗管理器确认列表中能找到“任我玩”（文件 `playwise.ovl`），并在仍可进入软件时熟悉打开方式。

标准包不在 `switch/playwise/` 根目录放置 PIN、密钥和运行规则。已有安装应按[升级](#升级)步骤保留这些数据；普通升级不要使用全量清理选项。

### 资格状态

当前候选仅以 Nintendo Switch OLED、HOS 22.5.0、Atmosphère 1.11.2 为资格目标。只有发布 Zip 的 SHA-256 与同目录 `qualification.json` 完全匹配，才能称该原包在记录环境已验证。没有匹配记录或使用其他环境时，应视为未验证。旧截图、主机预览和 Eden 模拟器结果均不是资格证据。

## 首次设置

第一次启动后，按向导完成五步。中途退出会保留进度，下次打开继续。界面若提示环境待确认或保护状态，先阅读页面原因；不要通过手工删除数据绕过检查。

1. **家长区入口**：`-` 键入口始终可用，按下后松开即可进入；也可选预设组合。任意组合录制仍在真机验证中，不是当前向导的可用入口。
2. **PlayWise PIN**：全新安装默认 `110`，建议立即修改。它只保护 PlayWise，不是 Nintendo 官方 PIN。输入时可使用触摸数字键盘或摇杆方向：八个方向为 `1`–`8`，`X` 为 `0`，`Y` 为 `9`，`ZL` 退格，短按 `+` 确认，`B` 取消；长按 `+` 约一秒可临时切到系统数字键盘。
3. **主题**：选择跟随系统、浅色或深色；只影响主机应用，浮窗保持自己的外观。
4. **确认接管**：核对环境和当前额度。PlayWise 保存安装前快照，在检测期间额度没有变化时保留当前总额度与剩余时间。
5. **进入区域**：进入家长区继续设规则，或进入孩子区查看今天安排。

## 日常设置额度

家长区由“今日调度、时间计划、离线加时、安全与偏好、支持与恢复”五个顶级页组成，按手柄 `L/R` 键即可循环切换。页面顶部状态栏实时显示本机时间、今天还可玩时间和状态更新时间；若状态超过 120 秒未更新或数据缺失，则显示“状态待确认”，避免把未知状态误判为零额度。

- **今日调度**：进入家长区后的默认首页，用于对今天的游玩额度进行即时、最高优先级的临时干预；
- **时间计划**：编辑周计划、国家节假日、临时日期额度计划、就寝时间和自主缓冲等长期规则；
- **离线加时**：在 Switch 本机或家长手机/电脑生成 8 位离线加时码，供孩子在受限时兑换；
- **安全与偏好**：修改 PIN、外观主题、家长区入口，并查看本机家庭活动记录；
- **支持与恢复**：独立顶级页，提供系统接管、重试修复、紧急停用、快照恢复与诊断导出。

### 今日调度

“今日调度”是家长管理孩子当天游戏时间的总控中心。它的核心设计原则是：

- **最高优先级临时覆盖**：今日调度的临时调整具有最高优先级，优先于临时日期计划、国家法定节假日额度和每周常规计划；
- **单日有效且不破坏长期计划**：所有今日调整仅在当天有效，次日 00:00 自动失效重置，控制规则无缝恢复为原定的常规计划，不会篡改或打乱已设置好的长期时间表。

![家长区今日调度预览](images/usage/parent/parent-dark.png)

今日调度页包含六张统一操作卡与一个全屏详情面板：

1. **今日额度（设置今日总额度）**：
   - **状态徽标**：卡片右上角实时指示今日额度的执行状态，包括“生效中”（绿色）、“未设置”（由下级长期计划决定）、“已清除”（本次会话内刚清除临时调整）、“等待生效”、“状态待确认”、“就寝立断”或“控制停用”。
   - **下级继承原因**：若今天未设置临时额度，动态副标题会明确说明当前由哪一层规则生效（例如“由每周常规计划决定”、“由国家法定休假决定”或“由临时日期额度计划决定”）。
   - **调整与安全确认**：按 `A` 键或触摸点击进入分钟调节器，可直接设定今天具体的总游玩时间。保存前界面会清晰对比“当前剩余时长 → 调整后预计剩余时长”；若调整可能导致主机立即耗尽额度，界面要求在实体手柄上长按 `A` 键或触摸确认按钮持续满 1 秒，以防止手滑误锁。
2. **快速加时**：
   - 专为临时奖赏或给予额外游玩时间而设计。提供 `+15 分钟`、`+30 分钟`、`+60 分钟` 快捷选项，以及自由增减的 `自定义` 分钟（范围 1–120 分钟）。
   - 选中后弹出二次确认面板，清晰对比当前剩余与加时后预计剩余；若遇到每日时间上限截断，会展示实际增加分钟数与琥珀色提示，核对无误后再确认提交。
3. **今日不限时**：
   - 适合周末聚会、节日庆贺或孩子表现优异时的单日免限制场景。
   - 确认提交后，今天不设游玩时间上限，状态显示为“不限时”；到次日 00:00 自动失效，无缝恢复常规时间计划。
4. **清除今日调整**：
   - 一键撤销上述对今天生效的所有临时干预（包括今日总额度、快速加时与今日不限时），使控制规则平滑回退到原本生效的下级计划（如周五计划或节假日安排）。
   - 若今天原本就没有临时调整，该卡片自动置灰禁用且不会提交无意义请求；若在当前主机应用会话中刚执行过清除，副标题显示“本次会话已清除，当前使用下级规则”。
5. **跳过本次就寝**：
   - 针对就寝时间限制（Bedtime）的单次放行卡。动态副标题显示当前正在生效或即将到来的就寝起止时间窗口（如 `21:00 至次日 07:00`）。若当前已在就寝限制中，卡片右上角显示“限制中”醒目标识。
   - 仅对“当前生效的这一场”或“今晚即将到来的这一场”就寝窗口执行一次性跳过，绝不修改或停用长期就寝计划，次日就寝窗口仍会自动锁定。
   - 点击后先刷新状态并锁定窗口实例，验证 PlayWise 管理 PIN，核对放行窗口后确认提交。
6. **自主缓冲**：
   - 展示今天自主缓冲福利（由家长在“时间计划 → 自主缓冲”中开启，可配置为每天一次 5、10 或 15 分钟）的可用状态。
   - 动态副标题清晰提示：“今日可领取 X 分钟”、“今日已领取，明天恢复资格”、“当前关闭，可在时间计划中设置”或“今天暂不可领取”。在限时来临时，孩子可在游戏内浮窗自主领取该缓冲。

#### 查看今日详情

在今日调度页按下手柄 `+` 键或触摸“+ 查看详情”，可打开全屏详情弹层，核对系统运作细节：

- **今日决策（Decision）**：完整展示当前额度的推导链条。自顶向下穿透检查“今日临时调整 → 临时日期计划 → 国家节假日 → 每周计划”，清晰展示各层规则的命中情况与最终生效值，同时列出就寝时间配置与自主缓冲状态。
- **使用与状态（Status）**：展示今天已玩时间的本机估算、近 7 天与近 30 天的有效游玩累计估算（缺失日期不自动补零），以及后台 sysmodule 的通信健康度（数据更新时间、数据新鲜度、IPC 传输路由状态）。

![今日决策详情预览](images/usage/parent/parent-details-decision-light.png)

### 长期和日期计划

周计划按星期编辑；国家节假日可设置法定休假与调休工作日；临时日期额度计划支持 1–366 天区间。编辑时先形成草稿，保存前核对对今天的影响。若今天被更高优先级规则覆盖，页面会说明今天额度不变；可能立即耗尽或状态待确认时，需长按确认。失败会保留草稿。

就寝时间可按每周、节假日和指定日期设置，允许跨夜窗口；三个子页面分别保存。切换或离开有未保存内容时，按提示选择保存、放弃或继续编辑。今日自主缓冲默认关闭，可设为每天一次 5、10 或 15 分钟；它增加今日额度，不改变就寝窗口。

## 离线加时

代码是由家长决定分钟数、当天有效的 8 位数字。生成代码不会立刻增加额度；孩子成功兑换后才能增加，且一枚代码只能成功使用一次。达到每日上限时，实际增加可能少于代码面额。家长可以通过电话、消息或当面告知孩子，PlayWise 不需要传输服务器。

### 在 Switch 上生成

1. 家长进入“离线加时 → 立即生成加时码”，验证 PlayWise PIN，选择代码时长后生成。
2. 核对代码有效日期和面额，再把 8 位数字告诉孩子。同日生成新代码不会撤销之前签发的代码；修改“下次加时时长”也不会改变已签发代码。
3. 若生成失败，按页面提示检查配置、SD 卡和时间。不要假设旧代码已撤销。

![主机生成入口预览](images/usage/grant/grant-entry-light.png)

### 在手机或电脑上生成

家长网页在当前浏览器本地计算 8 位码，不向 PlayWise 业务后端提交设备 ID、密钥或代码。无论采用哪种配对方式，生成时都要选择 **Switch 主机的本地日期**；家长设备与 Switch 日期不同时，以 Switch 显示的日期为准。

#### 推荐方案一：联网扫码

1. 让可信的家长手机或电脑接入网络，确认可以访问[公开家长网页](https://selfuppen.github.io/NX-PlayWise/)。该网页托管在 GitHub Pages，部分网络环境可能无法访问；也可以使用自己信任的 HTTPS 静态站点完整部署 `tools/ptc_frontend`。
2. 在 Switch 家长区进入“离线加时 → 手机/电脑生成加时码”，验证 PlayWise PIN，查看页面显示的二维码跳转地址。若使用自部署网页，先在“离线加时 → 加时码生成管理 → 编辑二维码跳转地址”填入其 HTTPS 地址，再返回二维码页面。
3. 用家长设备扫码打开网页，核对设备名，并选择“导入此设备”；若浏览器已有别的设备配置，先确认要覆盖。二维码包含加时码密钥，只能由可信的家长设备扫描。
4. 选好 Switch 本地日期与加时分钟数，生成代码，再通过电话、消息或当面把 8 位数字告诉孩子。孩子在 Switch 上兑换时无需联网。

![手机或电脑扫码配对页面，二维码使用公开演示配置](images/usage/parent/pairing-qr-demo.png)

图中的二维码已替换成公开演示配置，不能用于真实家庭设备。扫码只是将设备配置导入家长浏览器；网页生成代码仍在浏览器本地完成。若网页无法访问，使用下方的单文件离线版或[在 Switch 上生成](#在-switch-上生成)。

#### 备用方案二：单文件离线网页

1. 从Release 页面的完整交付包(`playwise-complete-<版本>.zip`)，解压后取得 `playwise-offline.html`。在 Switch 家长区进入“离线加时 → 加时码生成管理 → 导出手机/电脑配置”，验证 PlayWise PIN，导出 `sdmc:/switch/playwise/parent-import.json`。
2. 把 HTML 和配置文件传到可信的家长手机或电脑。手机先保存文件，再交给系统浏览器打开 HTML；不要使用聊天软件或网盘内置预览器。
3. 在网页中选择“导入配置文件”，选取 `parent-import.json`，核对设备名并选择“导入此设备”。之后选择 Switch 本地日期和分钟数，即可离线生成 8 位码；孩子兑换也无需联网。

![当前单文件家长网页，使用公开演示配置](images/usage/parent-offline-demo.png)

单文件版无需安装应用、Python、前端工具或本地服务器，但不能作为二维码跳转地址，也不能安装成 PWA。若浏览器禁止本地文件持久存储，下次打开时需重新导入配置。`parent-import.json` 和二维码都包含生成代码所需的密钥；不要公开、发送给孩子或上传到不可信站点。修改 Switch 上的加时码密钥后，家长设备须重新配对，旧密钥签发的代码不再有效。

### 孩子在主机应用兑换

未受限且还能启动 Homebrew 时，打开“任我玩”进入孩子区，选择“输入加时码”，填入 8 位数字。核对兑换前和预计兑换后时间，再确认；高风险情况会要求长按。成功页显示实际增加和当前可确认的剩余时间。结果仍在确认中时，等待或重新打开查看原结果，不要重复提交。

### 受限时使用游戏内浮窗

当每日额度耗尽或进入就寝限制后，系统原生弹窗会阻断普通软件与 PlayWise 主机应用。此时在游戏内随时通过快捷键呼出浮窗（`playwise.ovl`），即可进行 8 位加时码兑换、领取自主缓冲，或由家长输入 PIN 进行应急调整。完整操作界面、快捷键与恢复流程详见下一章[游戏内浮窗 (Overlay)](#游戏内浮窗-overlay)。

## 游戏内浮窗 (Overlay)

游戏内浮窗（文件路径 `sdmc:/switch/.overlays/playwise.ovl`）是 PlayWise 在 Switch 运行时的核心组件之一，基于 Tesla / Ultrahand 等浮窗环境构建。

> [!IMPORTANT]
> **浮窗的不可替代性**：
>
> 1. **游戏内免切出**：孩子或家长在游玩任何游戏时，随时按下浮窗快捷键（如默认的 `L + 十字键下 + 右摇杆按下 R3`）即可呼出浮窗，实时查看剩余时间或输入加时码，无需退出当前正在运行的游戏。
> 2. **系统受限阻断时的唯一主机自救通道**：当每日游玩额度耗尽或就寝时间生效时，Nintendo 官方 PCTL 弹窗会强行阻断所有游戏、Homebrew Menu、系统设置及 PlayWise 主机应用（NRO）。此时，**游戏内浮窗是主机端唯一可运行的 PlayWise 交互与恢复入口**。

### 日常浮窗面板（未受限状态）

在日常游戏过程中呼出浮窗，显示专为掌机与手柄优化的固定深色界面：

1. **顶部状态胶囊与额度栏**：
   - **额度与耗时**：左侧展示今日使用估算与额度模式（如“今日已用约 45 分钟”或“今日不限时”）；
   - **今天还可玩**：核心区域以 22px 绿色数字醒目显示当前剩余分钟数（最长显示 1440 分钟）或“不限时”；
   - **刷新按钮与新鲜度**：右上角显示数据新鲜度（“刚刚刷新”、“X 秒前”；超过 30 秒提示“数据可能已过期”）。按手柄 `Y` 键或触摸点击可手动刷新状态；加时提交后显示橙色“正在刷新… / 确认中”。
2. **受限预警与护眼提醒**：
   - 额度下方动态显示当前状态引导（如“剩余时间充裕”、“请注意适度休息”或就寝时间提醒）。
3. **8 位加时码输入卡槽**：
   - 居中排列 8 个数字卡片槽，当前光标槽高亮闪烁，显示光标指示符 `_` 与青绿色边框；
   - 槽位下方实时显示已输入位数（如“已输入 4/8 位”）、当前高亮选中的数字，以及**主机当前的本地日期**（防范跨时区或日期错误签发）。
4. **3×4 触控/手柄数字软键盘**：
   - 布局包含数字 `0`–`9`、第四行左侧的 `X 退格`（琥珀色边框）以及右侧的 `点按清空`（红色边框）；
   - **双模操作**：手柄可通过左摇杆或十字键在网格中移动焦点，按 `A` 键输入，按 `X` 键退格；也可直接在 Switch 触摸屏上点按数字键。
5. **操作与提交栏**：
   - 输满 8 位数字后提交栏高亮激活，按手柄 `+` 键或点击按钮即可提交；
   - **非阻塞设计**：后台向 sysmodule 处理请求期间，本地输入界面不冻结，仍允许继续编辑数字、移动光标或按 `B` 键关闭。
6. **两阶段安全兑换与防误触确认**：
   - 提交后首先进入**加时预览面板**（非消费性验证），展示加时面额、当前还可玩时间与兑换后预计可玩时间；
   - **危险长按确认机制**：若兑换后仍为 0 分钟、从不限时被改为限时、或无法确认剩余时长，界面会以深红底色高亮警示，此时**必须在实体手柄上长按 `A` 键满 1 秒**才能确认，触摸屏点击将被拦截并提示使用手柄长按，彻底防止误触；普通安全兑换只需短按 `A` 或 `+` 键确认；按 `B` 键可随时取消且绝不消费代码；
   - **掉电保护与结果恢复**：若在提交后或网络/后台响应期间意外退出或断电，下次重新打开浮窗会自动恢复未完成的加时事务，并展示最终结果，绝不吞码或重复提交。
7. **底部可折叠命令与状态栏**：
   - 按手柄 `-`、`L`、`R` 键或触摸点击状态栏可随时展开/收起；
   - 展开后可查看最近执行命令、通信传输路由（IPC 进程间通信或 SD 卡请求队列），以及后台返回的详细中文原因与错误码。

### 受限恢复模式（额度耗尽或就寝阻断）

当每日额度耗尽或就寝时间到来，系统被 Nintendo 原生弹窗阻断时，按下快捷键呼出浮窗，界面会自动切换为**限制恢复面板**，明确标明限制原因与就寝窗口：

#### 1. 孩子自主恢复通道（未受就寝锁定时）

- **按 `A` 键输入 8 位加时码**：孩子拿到家长给予的代码后，按 `A` 即可进入 8 位卡槽输入界面，完成验证并立即恢复游戏；
- **按 `+` 键领取自主缓冲**：若家长在“时间计划”中开启了自主缓冲且今天尚未领取，界面会提示 `+  领取自主缓冲  +X 分钟`。孩子按下 `+` 键即可一键延展今日时间，PCTL 弹窗随即解除；若今日已领过，则提示“今日已使用自主缓冲（明日恢复）”。

#### 2. 家长应急授权通道（按 `X` 键）

当家长在主机旁且需要临时放行时，无需退出到桌面，直接在浮窗按 `X` 键进入**家长 PIN 授权页**：

- **PIN 输入与安全防爆**：方向键选择数字，按 `A` 输入，`X` 退格，`Y` 清空，按 `+` 验证。系统共享 PlayWise 的防爆破保护，连续输错将触发倒计时冷却；
- **单次授权三项恢复动作**：PIN 验证成功后，家长可使用方向键选择并执行一项应急动作：
  - **若处于每日额度耗尽**：
    1. **今日增加 X 分钟**：按左/右方向键以 5 分钟为步长自由调整（范围 5–120 分钟），按 `A` 键立即执行并重读 PCTL；
    2. **今日不限时**：手柄长按 `A` 键 1 秒确认执行，彻底解除今日额度限制；
    3. **恢复安装前 PCTL 快照并停用 PlayWise**：遇到严重控制异常时，手柄长按 `A` 键 1 秒确认，将官方 PCTL 还原为安装前状态并停用 PlayWise 后台。
  - **若处于就寝限制中**：
    1. **跳过本次就寝**：按 `A` 键立即执行，仅放行当前这一场或今晚就寝窗口一次，次日自动恢复常规就寝；
    2. **关闭就寝计划**：手柄长按 `A` 键 1 秒确认执行，停用长期就寝计划；
    3. **恢复安装前 PCTL 快照并停用 PlayWise**：手柄长按 `A` 键 1 秒确认执行。
- **真实底层状态核验**：恢复动作执行后，浮窗会强制重新向系统 Horizon PCTL 服务查询实际控制状态。如果就寝已跳过但每日额度仍为 0，浮窗会据实提示“就寝限制已移除，但仍受每日额度限制”，绝不向用户给出虚假的“完全解除”提示。

> **Nintendo 官方弹窗与 PlayWise 浮窗的关系**：
> 官方 PCTL 到时弹窗属于 Nintendo Horizon 系统原生的阻断行为。弹窗上提示的“输入 PIN 临时解除”使用的是 **Nintendo 官方家长控制 PIN**；而在 PlayWise 浮窗中使用的则是 **PlayWise PIN**。两套系统各自独立工作，互不冲突。

## 升级

### 保留数据的覆盖升级

标准包只覆盖程序资产和默认模板，不覆盖 `switch/playwise/` 根目录中的 PIN、密钥、规则、账本、日志和安装前快照。升级前仍建议备份数据，并完整覆盖新包的 `atmosphere` 和 `switch` 两个目录，不要只复制某个二进制。

- **关机读卡器升级**：关闭 Switch，取出 SD 卡，在电脑上合并覆盖两个目录，安全弹出并重启。首次打开后按提示完成安全重新检测。
- **开机传输并热加载**：先关闭 PlayWise 主机应用和浮窗，用 DBI/MTP、FTP 或 USB 完整覆盖标准包，再打开主机应用进入家长区，核对当前与待加载构建，确认“加载新版”。等四阶段完成、新后台身份与 IPC 重连确认后重新打开浮窗。取消后可从“支持与恢复 → 软件信息”重新进入。

如提示安装不完整，重新覆盖**同一个**标准包。旧后台不支持安全交接、目标身份不匹配或启动失败时，按提示完整重启；程序不会强制终止旧后台或自动重启主机。传输未完成时不要启动热加载。

Windows 的 DBI/MTP 保留数据脚本可先预览再执行：

```powershell
.\tools\install_package_via_dbi_mtp.ps1 -SourceFolder .\build\packages
.\tools\install_package_via_dbi_mtp.ps1 -SourceFolder .\build\packages -Apply
```

普通升级不要对安装脚本使用 `-Clean`、`-Full` 或 `-CleanAll`。FTP 全量清理和 Device Lab 安装会影响现有数据或控制环境，只供明确需要的维护者按[测试指南](测试指南.md)操作。普通用户只安装标准包，不同时启用两个后台。

## 常见问题

- **代码提示无效、日期不符或已使用**：核对 Switch 显示的本地日期、设备配置和输入数字。明确提示已使用时请家长新生成一枚；失败或预览取消不应消耗代码。
- **额度仍显示旧值**：等待同步结束后按 `Y` 刷新。超过 120 秒的状态或缺少读数会显示待确认，不应根据旧余额推断限制是否解除。
- **设置今日总额度后显示“已到限制”、还可玩 0 分钟，但游戏仍能打开**：先检查 Nintendo 官方家长控制已启用“时间到了暂停软件”，并确认没有通过官方 PIN 临时解除限制。若开关正常，可尝试联网校准 Switch 时间：在 DBI 中选择“工具 → NTP 时间同步”，或使用 [QuickNTP（Tesla 时间同步工具）](https://github.com/ppkantorski/QuickNTP)。同步成功后回到 PlayWise 刷新状态，并用没有未保存进度的游戏重新验证是否实际暂停。校时只是一个可能的解决方法，参见[Issue #1](https://github.com/selfuppen/NX-PlayWise/issues/1)；若仍可打开游戏，按下一条继续排查，必要时从“支持与恢复”导出诊断。
- **官方倒计时或到时暂停不工作**：先暂停 PlayWise 设置，检查 Nintendo 官方家长控制及“时间到了暂停软件”，在非关键游戏上重新验证。PlayWise 不能替代官方 PCTL 的计时和阻断。
- **家长网页无法保存配置**：从系统浏览器打开单文件版；若浏览器限制本地文件存储，下次重新导入。需要扫码配对或桌面安装时改用可信 HTTPS 页面。
