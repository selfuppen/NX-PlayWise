## 从哪里开始

- 安装与日常使用：先读[使用指南](使用/使用指南.md)，自制地区日历时再读[日历格式](使用/自制节假日日历格式.md)。
- 开发与验证：先读[开发环境指南](开发/开发环境指南.md)，再读[开发指南](开发/开发指南.md)和[测试指南](开发/测试指南.md)。
- 协议与控制逻辑：对照[协议](设计/协议.md)和[PCTL 集成架构](设计/PCTL集成架构.md)，UI 配色与排版遵循[视觉风格与设计指南](设计/视觉风格与设计指南.md)，日历数据来源见[节假日日历数据](设计/节假日日历.md)。
- 探索新能力：阅读下方调研记录；其结论与待验证方案不代表已发布能力或当前候选的真机资格。

## 文档维护

新增文档按用途放入以上目录，并更新本索引及[英文索引](README_en.md)。中英文版本在同目录互链，引用其他分类时使用相对路径；仓库根目录起算的命令和源码路径保持原样。

调研保留日期、来源版本及待验证边界；已发布行为和稳定契约分别维护在使用、开发与设计文档中。真机验收记录如需纳入仓库，集中放入 `开发/验收记录/` 并从测试指南链接，不把调研结论当作验收证据。

`images/usage/` 和 `images/usage-en/` 保持现有路径，预览同步流程见[使用指南的文档与截图维护](使用/使用指南.md#文档与截图维护)。本目录的两份日历格式旧路径仅保留导航，供已发布应用中的帮助网址继续访问；正文只维护在 `使用/`。
