## 从哪里开始

- 安装与日常使用：先读[使用指南](使用/使用指南.md)，自制地区日历时再读[日历格式](使用/自制节假日日历格式.md)。
- 已安装后的升级：查看[手动热更新步骤](使用/使用指南.md#手动热更新操作步骤)和[版本／构建 ID 核对](使用/使用指南.md#热更新后版本与软件信息如何变化)。
- 卸载或清空重装：查看[完全删除后重新安装](使用/使用指南.md#完全删除后重新安装)，可选四步最简重装，或展开恢复原设置与备份的完整流程。
- 开发与验证：从[开发文档入口](开发/README.md)查阅完整分类；首次搭建环境先读[开发环境指南](开发/开发环境指南.md)，再读[开发指南](开发/开发指南.md)和[测试指南](开发/测试指南.md)。
- 协议与控制逻辑：对照[协议](设计/协议.md)和[PCTL 集成架构](设计/PCTL集成架构.md)，UI 配色与排版遵循[视觉风格与设计指南](设计/视觉风格与设计指南.md)，日历数据来源见[节假日日历数据](设计/节假日日历.md)。
- 探索新能力：下方调研记录汇总技术方案与历史调查，已发布功能以使用和设计文档为准。

## 文档维护

新增文档按用途放入以上目录，并更新对应分类索引与[英文索引](README_en.md)。中英文版本在同目录互链，引用其他分类时使用相对路径；仓库根目录起算的命令和源码路径保持原样。

调研记录保留日期和来源版本；已发布行为和稳定契约维护在使用、开发与设计文档中。真机验收记录和阶段性进度总结集中放入 `开发/验收记录/` 按月归档，不堆积在根目录或稳定指南开头。

`images/usage/` 和 `images/usage-en/` 保持现有路径，预览同步流程见[使用指南的文档与截图维护](使用/使用指南.md#文档与截图维护)。本目录的两份日历格式旧路径仅保留导航，供已发布应用中的帮助网址继续访问；正文只维护在 `使用/`。
