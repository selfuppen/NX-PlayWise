# 自制地区节假日日历格式

家长可为一个国家或子地区制作一年的日历。将 UTF-8 JSON 文件放在 SD 卡 `/switch/playwise/calendar-import/`，在 Switch 家长区打开“时间计划 → 节假日安排 → 管理日历 → 导入文件”，选择文件，检查日期预览并确认。导入仅更新日历库。之后在“已保存地区”选择地区，查看今日及未来七天预览，再长按确认应用；即使重新导入当前地区，也须重新应用。一次只应用一个地区，该地区已导入的各年份一起生效。内置“中国大陆（内置）”始终是独立选项。

导入内容始终显示为“用户导入”，PlayWise 不核实其官方来源。所选地区缺少某一年时，该年显示“未覆盖”，额度和就寝规则按每周计划回退。文件没有额度、就寝时间或时区字段；日期按 Switch 主机的本地完整日解释。

## 管理页操作与格式提示

管理页的按钮均可直接触摸。`B` 返回节假日编辑页，`Y` 刷新 SD 卡文件列表、地区库及后台状态，`X` 打开简要格式说明；格式弹窗按 `A`、`B`、`+` 或触摸返回按钮关闭，保留原来的页签、页码和选中项。`L/R` 切换“已保存地区 / 导入文件”，上下键选择项目，左右键或 `ZL/ZR` 翻页，`A/+` 打开导入或应用确认。刷新中仍可返回或查看格式说明，不能重复导入、应用或刷新。

格式弹窗只概括保存目录、UTF-8 JSON、必填字段、日期格式、年份与大小限制，以及“导入后仍需应用”。制作文件时请按下文的完整规则和示例核对；格式版本固定为 1，重新导入内容不需要修改它。

## 字段

| 字段 | 要求 |
| --- | --- |
| `format_version` | 固定整数 `1`，表示文件格式，不是内容修订号。 |
| `region_id` | 2–16 位大写英文字母、数字或内部连字符；例如 `JP`、`US-CA`。 |
| `region_name` | 非空显示名称，UTF-8，最多 64 字节。同一个 ID 的各年份须使用同一名称。 |
| `year` | 整数，2020–2198。一个文件只覆盖这一年。 |
| `holidays` | 可为空的数组。每项有非空 `name`、`from`、`to`；起止日期均包含在内。 |
| `workdays` | 可为空的日期字符串数组，表示需要按特殊工作日规则处理的完整日。 |
| `source_note` | 可选的非空来源说明，最多 128 字节；此说明不构成官方认证。 |

日期严格为 `YYYY-MM-DD`，必须是真实日期且属于 `year`。假日区间起点不得晚于终点；假日之间、工作日之间，以及假日与工作日均不得重复或冲突。最多 64 个假日分组；文件大小不超过 16 KiB。文件名限 1–75 个字母、数字、`-`、`_`、`.` 后接 `.json`，不能包含路径分隔符或 `..`。

## 完整示例

将以下内容保存为 `JP-2028.json`，编码为 UTF-8。示例日期仅演示格式，由家长自行核对当地官方安排。

```json
{
  "format_version": 1,
  "region_id": "JP",
  "region_name": "日本（自制示例）",
  "year": 2028,
  "holidays": [
    {"name": "示例新年假期", "from": "2028-01-01", "to": "2028-01-03"},
    {"name": "示例春季假期", "from": "2028-03-20", "to": "2028-03-20"}
  ],
  "workdays": ["2028-01-08"],
  "source_note": "家庭自制测试数据；请先核对当地发布安排"
}
```

`2028` 是闰年，`2028-02-29` 也是合法日期。没有假日或特殊工作日时，分别使用 `"holidays": []` 和 `"workdays": []`；两个字段仍须存在。

## 错误示例

以下文件会被拒绝，因为 2027 年没有 2 月 29 日，且假日与工作日日期冲突：

```json
{
  "format_version": 1,
  "region_id": "US-CA",
  "region_name": "加利福尼亚州",
  "year": 2027,
  "holidays": [
    {"name": "无效日期", "from": "2027-02-29", "to": "2027-02-29"},
    {"name": "重叠示例", "from": "2027-05-01", "to": "2027-05-03"}
  ],
  "workdays": ["2027-05-02"]
}
```

修改同地区同年的文件后可再次导入，不用提高 `format_version`。日历库保留按摘要命名的文件，新的导入更新该地区该年的库索引；当前已应用版本仍固定，直到家长再次确认应用。导入或应用时如显示文件改变、摘要不匹配或文件损坏，请重新检查 SD 卡文件，再从管理页刷新预览。
