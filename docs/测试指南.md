# 测试指南

项目只保留一个本地测试入口、一个远程打包入口和一次真机快速测试。协议拒绝路径、nonce、backup gate、PCTL 失败和恢复细节由自动测试覆盖，不再要求每次在真机逐项重做。

## 本地测试

Windows PowerShell：

```powershell
python .\tools\test.py
```

成功时只输出：

```text
PASS: local tests
```

该命令无第三方依赖，覆盖：

- token v1、observe queue、Web 辅助界面和远程打包工具回归。
- `protocol_probe` 的 init、离线码、observe 处理、result 和队列归档。
- observe 不消费 nonce。
- safe package 布局、默认 observe 和无 `boot2.flag`。
- 缺少 sysmodule 时禁止生成 boot2 package。

只有排查具体失败时才直接运行 `tests/` 下的单个脚本。

## 远程打包

涉及 C、Makefile、Companion NRO、sysmodule 或 package 的改动，先提交并推送 `master`，然后运行：

```powershell
python .\tools\package_remote.py
```

脚本通过一次 SSH 会话完成以下工作：

1. 宿主机仓库快进到 `origin/master`。
2. devkitPro 容器运行完整 C/Python 测试。
3. 构建 Companion NRO、sysmodule NSP 和全部 package。
4. 校验并下载五个 zip：`safe-nro`、`disabled-boot2`、`observe-boot2`、`grant-boot2`、`enforce-boot2`。
5. 将 zip 解压到同名目录。

Windows 默认输出目录：

```text
D:\switch\play-time-controll\download
```

需要其他目录时使用：

```powershell
python .\tools\package_remote.py --output <目录>
```

下载先写入临时目录。构建、传输或校验失败时，上一次成功下载的 package 保持不变。

## 真机快速测试

日常真机验收只运行快速 PCTL effect probe，不再执行 A-F 阶段、拒绝用例矩阵、手工 1 分钟授权码或 enforce snapshot。

前置条件：

- 已掌握 SD 卡读写方式和官方家长控制 PIN/App。
- 知道如何创建 `sdmc:/switch/play-time-control/flags/disable.flag` 和移除 `boot2.flag`。
- 远程打包已通过。

操作：

1. 将最新 `grant-boot2-<timestamp>.zip` 解压到 SD 卡根目录并重启进入 Atmosphere。
2. 启动 Companion，进入家长区，选择 `Quick device test`，输入 `YES`。
3. 等待页面显示 `Quick device test PASS`。

一次快速测试自动覆盖 request queue、真实 PCTL 会话、写前备份、目标写入、StartPlayTimer、运行时状态读取、能力持久化和原始设置恢复。PASS 必须同时满足：

- result 为 `probe_play_timer_effect`、写入模式、非 dry-run。
- `pctl_effect_probe.verdict` 为 `pass`。
- raw settings 和 timer enabled 状态均已恢复。
- `play_timer_write_verified` 与 `play_timer_effect_verified` 均已持久化。
- backup、`effect_before` 和 `effect_restore` 证据存在。

失败、超时或自检不通过时，Companion 自动创建 `disable.flag` 并显示 `FAIL`。不要继续 grant、enforce、raw block 或 suspend；保留 result、logs、capabilities 和 backup 排障。

## 恢复

按以下顺序处理：

1. Companion 家长区选择 `Emergency disable`，创建 `disable.flag`。
2. Companion 无法启动时，从 SD 卡创建 `sdmc:/switch/play-time-control/flags/disable.flag`，然后重启。
3. 需要完全停止 boot2 时，删除 `sdmc:/atmosphere/contents/4200000000BD2300/flags/boot2.flag`，或安装 `disabled-boot2` 包。
4. 官方 play-time 限制或 Suspend Software 已生效时，使用官方 PIN 或 Nintendo Parental Controls App 解除。

恢复期间不要删除 `backups/last_pctl_backup.txt`、`results/` 或 `logs/`。确认问题解决且目标模式正确后，才能在 Companion 中选择 `Resume control` 删除 `disable.flag`。

## 能力边界

- 快速测试是日常真机权威入口，但不验证 raw block 或 suspend；两者继续受 capability gate 保护。
- expiry probe 仅用于专项排障，不是普通验收项。
- `safe-nro` 和 `observe-boot2` 保留用于 UI 或只读专项排障，不属于日常流程。
- 请求字段、错误码和结果结构以 `docs/协议.md` 为准。
