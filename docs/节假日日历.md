# 节假日日历数据

PlayWise 的国家节假日规则运行时不联网，也不依据农历或固定算法推算调休。年度数据只依据国务院办公厅正式通知人工整理，经确定性 C 测试和统一 package 门禁校验后编译进规则核心。

## 更新与回退

同一年份的新数据必须提升版本；相同版本内容不得改变，也不接受正常降级。未来开放离线导入时，新文件必须先完整解析、校验和原子持久化，成功后才能替换旧表。首版只提供内置表，不实现导入或数字签名。

日历覆盖终点前 30 天开始提示更新。进入未覆盖年份后，国家节假日层停止参与规则选择并回退每周计划；今日临时设置仍保持最高优先级。

当前威胁模型假设儿童无法修改主机日期或直接篡改 SD 卡数据，因此首版不实现系统时间回退检测和日历包签名。
