## 交互与业务边界

- **额度优先级固定**：今日调整 (P1) > 指定日期额度 (P2) > 地区节假日 (P3) > 每周计划 (P4)；就寝、护眼、电视规则各自独立生效。
- **关闭不丢配置**：节假日总开关、指定日期开关与就寝总开关关闭时，已填规则完整保留为待启用预设，不清空分钟数或时段；切为不限时保留此前限时分钟数。
- **区间与日期边界**：指定日期一次保留一个闭区间，持续天数 1—366 天；明确区分“今天在区间内 / 未来生效 / 区间已过 / 已关闭”，避免误导文案。
- **就寝分区与例外边界**：按现有协议，保存与放弃均针对“总开关 + 当前就寝子页（每周／节假日／指定日期）”；`Y 跳过本次 / X 恢复本次` 仅作用于当前或下一生效窗口，不修改长期规则。
- **未知与危险门禁**：状态过期时保持“待确认”，不猜测余额或生效来源；保存后将立即耗尽今日额度或立即进入就寝限制时，保留原危险警示与长按确认门禁。
