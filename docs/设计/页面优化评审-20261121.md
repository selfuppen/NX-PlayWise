## 如何预览与选择

HTML 为独立文件，内嵌原图、样稿、四套仓库调色板与脚本，无网络依赖。左侧选择页面，上方切换「真机原图」「代码渲染图」「A / B 对照」，并可选择明暗主题及固定示例状态。放大后可点击样稿中的操作查看原有导航与确认路径。

每页独立选择 A 或 B，可以混搭，也可以标为待定。选择与中文备注只写入当前浏览器；「导出 JSON」「导出文字」可保存选择及原图哈希，不提交到设备或外部服务。浏览器未允许本地存储时仍可导出。当前是简体中文布局评审，浏览器字体与实际 Switch 字体不同。

五类示例分别为正常使用、护眼休息、多项限制并发、状态待确认、今日不限时。数值属于固定示例，不与历史原图逐项比较。

### 保留的业务与交互边界

- 今日总额、护眼、就寝与非电视限额各自独立；加时、缓冲和今日不限时不自动解除其他限制。
- 示例中正常状态的今日余额为 51 分钟、非电视余额为 18 分钟，按当前模式预计 15 分钟后需护眼休息；三个数字不混为同一个「还能玩多久」。
- 过期状态隐藏当前余额、累计与推演，不显示旧值为当前值；七日可读基准明确标为每周基准，实际额度待确认。
- 全部并发限制保留；倒计时到零仍需后台确认。不可用动作保留原因，不假装执行成功。
- PIN、长按、请求回执与失败回滚沿用原契约；样稿中的按钮只展示路径。动态主操作定稿后须验证焦点稳定，刷新期间不突然重排。
- NRO 使用仓库四套双主题调色板；Overlay 固定深色、448×720 面板及 Y=648 开始的 Tesla 页脚。对应状态文字、数值和操作分层，图标为可用简单几何。

## 修订 2：按用户选择协调布局

[打开修订 2 HTML](ui-layout-review-batch1-20261121-r2.html)。第一版 HTML 保留原件。新文件继承六张原图及同一调色板，使用独立浏览器存储，不改写第一版选择。

本次明确选择与问题为：孩子首页采用 B，协调「今日总余额」下方未占满的空间；家长「今日安排」组合 B 左侧与 A 右侧；浮窗两案难以区分，需核对并重新出图。孩子与家长方向已在新版记录，浮窗仍待选择。

- **孩子 B**：余额位于左侧，今日已用与今日总额右对齐；下方三条守护信息按剩余高度等分。看板从 300px 增为 320px，七日区域相应缩为 188px，分组保留 16px 间距，主体整体高度不变。三条守护行均约 53px，最后一行距卡片底边 17px（含边框）。状态卡与余额卡底边对齐，七日区域与右列动作区底边对齐，避免隐性溢出或空白占位。
- **家长合并版**：左侧沿用 B 的「状态结论 → 余额 → 独立规则」，右侧完全沿用 A 的快速加时整行、三项额度操作与四项今日操作。原 A / B 可在上方切换；五种状态下合并版左侧内容与 B、右侧内容与 A 分别一致，八项动作及顺序保留。
- **浮窗两案**：第一版共用紧凑 CSS 隐藏了 B 的分区标题，正常状态又复用主体结构，导致差异不明显。本次拆为独立布局：A 是左对齐状态卡 + 2×2 总览格，保留四项短说明；B 是居中原因大卡 + 四行全宽状态清单，受限时家长处理成为实心主按钮。两案使用同一业务示例，所有并发原因保留。对照视图放大展示 448×720 面板，避免完整主机画布将浮窗压缩成窄条；真机原图继续完整显示。

新版默认打开修订后的孩子 B；进入家长页直接展示合并版；进入浮窗页默认展示护眼休息状态的 A / B 面板对照，也可切换正常、并发、未知和不限时。
