## 现行页面诊断（基于真机实拍与第 1 批合并后代码渲染）

对照历史真机实拍与当前 `docs/images/usage/child/*.png` 生产渲染图，梳理出 7 项影响直观性与质感的核心痛点：

1. **Emoji 与纯矢量图标双拼及不统一**：`未来 7 天时间计划` 出现蓝矢量日历 + 红色 `📅` 双图标；`输入加时码` 出现矢量键盘 + `🎁`；三条守护中仅 `📺 电视模式规则` 带 Emoji 而护眼/就寝无图标；顶栏应用图标旁多出 `⭐`。
2. **左侧主状态卡配色僵化、大片留白、文案重复**：无论「现在可以玩」「总额度耗尽」「连接底座继续使用」还是「护眼休息」，左卡永远是同一块深蓝底，1 秒内难以区分健康/休息/受限；缺少可视化进度环；底座受限时「连接底座继续使用」在标题与底文重复两次。
3. **今日总余额缺进度条、0 分钟仍亮蓝字、守护关闭态刷屏且截断**：余额区缺少消耗进度条；额度耗尽时 `0 分钟` 仍用主色亮蓝（非警示红）；三项守护关闭时连续重复 6 次「关闭」，且电视规则副文直接 `...` 截断；`周计划` 在顶栏、余额卡与今日日卡重复出现 3 次。
4. **右列操作权重模糊、对齐偏心、禁用态不解释原因**：除首卡外其余 3 张全用同色浅蓝底，儿童日常动作与「家长区」管理入口未分层；左图标配右侧居中文字重心偏斜；`A / X / +` 为纯文本而非键帽；`今天没有可领取的自主缓冲。` 含多余句号；不可用时副文仍显示「只增加今日总额度」，未告知具体受限原因。
5. **底部 7 日计划条“明天”抢占“今天”高亮**：`ui_render_child.c` 将 `is_tomorrow` 赋为主色标题、主色来源与主色底条，反而让「今天安排」配灰色底条，视觉焦点颠倒；每格重复 5 遍微小 `每周计划基准` 且缺少直观时长对比条。
6. **新版本徽章挤压顶栏**：`child-update-available-light.png` 中 `↓ 软件有新版本` 紧贴副标题与顶栏底线，显得局促。
7. **手柄初入无聚焦指引**：初入页面时 `child_actions_focused = false` 且 `child_forecast_focus = 0`，手柄用户缺少十字键可达性提示。

## 三套 1280×720 方案对比（修订 3：按重要性重构，聚焦当天规划与未来 7 天）

修订 3 彻底按小朋友的真实信息重要性重新排布屏幕面积与视觉权重：

- **主角 1 · 今日游玩规划（核心是「按当前模式持续使用预计」）**：直接复用 `companion/nro/ui_status_state.c` 中现成的 `ptc_ui_project_today()` 推算引擎，不再缩在角落，升级为 44–50px 超大分段轨道或全高竖向作息时间线，让孩子一眼看清“现在能玩多久 → 几点护眼休 → 几点续玩 → 几点因何停用”。
- **主角 2 · 未来 7 天计划**：扩容至宽敞 7 日大日历或 7 行水平柱状对比表，自带今天已玩/剩余双色条与每晚就寝时间，取消 7 遍重复打印的 `周计划`。
- **弱化其他信息 + 全面去重**：撤销独立的「今日总余额大卡」与「护眼 / 就寝 / 电视规则三连大卡」，余额融合进主状态区，已生效规则以极简内联微标呈现、未开启项全部隐去（零“已关闭”刷屏）；将「输入加时码 / 领取缓冲 / 使用详情」与「家长区」压缩为单行极简底条或超窄弱化侧栏，全屏 **82%～90%** 面积归还给当天规划与未来 7 天。

评审 HTML 内置 **方案 A / B / C** 三套纯 CPU 软件渲染可落地的 1280×720 方案，支持浅／深主题、仓库 4 套风格（石墨／纸墨／雾青／暮霭）、7 大真实业务场景切换、页内点击顶栏模式胶囊实时重算、领取缓冲顺延、7 日卡片联动、放大预览与结论导出。

| 方案 | 空间配比（今天 / 7天 / 操作） | 持续使用预计与 7 日呈现方式 | 适用偏好 |
| --- | --- | --- | --- |
| **方案 A（推荐）· 全宽双主角** | 今日规划 54% + 未来 7 天 34% + 极简底条 10% | 上半全宽「今日规划卡」内嵌 868px 超宽 44px 分段轨道 + 大号时刻阶段卡；下半全宽 7 日宽敞大日历（含今天双色进度条与每晚就寝）；操作与家长区收敛为底端 46px 单行 | 视觉重心最稳、信息最舒展、全屏无压迫感 |
| **方案 B · 左今日竖向作息表 + 右 7 天对比条** | 今日时间线 56% + 7 日水平柱表 36% + 右底操作 8% | 左侧全高竖向日程时间线（像课程表自上而下阅读每段起止时间与事项）；右侧 7 行水平时长柱状对比，哪天多哪天少一秒看穿 | 偏爱“作息表”式竖向阅读与 7 天水平长度直观对比 |
| **方案 C · 左 82% 关卡时间尺与 7 日 + 右窄动作栏** | 左今日 + 7 日 82% / 右窄动作栏 18% | 保留“左看右点”经典方向感，但右列瘦身至 196px 超窄浅色操作条；左侧 972px 展示 50px 超高分段尺 + 箭头串联步骤卡 + 加高 7 日卡 | 希望保留右列快捷操作手顺，同时大幅弱化按钮权重 |

## 交互与业务边界

- 每日总额、护眼、就寝与非电视限额继续保持严格独立；加时码与自主缓冲绝不暗示可解除非额度限制。
- “本次预计可连玩”与“今日总余额”严格区分；缺失/过期快照保持待确认并触发琥珀待刷新引导，不把缺失读数显示为零。
- 所有图标均采用纯 CPU 矢量几何（圆弧、圆角矩形、线段），三案均严格使用 `companion/nro/ui_theme.c` 四风格 × 双主题语义色表。
