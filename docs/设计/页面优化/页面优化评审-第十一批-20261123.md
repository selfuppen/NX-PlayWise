## 后续分批实现指导（代码落点与约束）

实施第 11 批时建议拆为「Web PWA」与「NRO 主题 + 向导微调」两个独立提交，互不阻塞：

1. **手机端离线发码 PWA（`tools/ptc_frontend/`）**
   - 涉及文件：`tools/ptc_frontend/index.html`、`tools/ptc_frontend/styles.css`、`tools/ptc_frontend/app.js`（以及相关前端测试 `tests/`）。
   - 关键改动：
     - 当 `localStorage` 中已存在配对设备时，默认收起 `#pairingSettings`（或移入抽屉/第二 Tab），把首屏 100% 留给 `#pairedBar` + 档位快选 + 日期快选 + 超大 4-4 分组结果码卡。
     - 保持 4 套外观风格（`default/paper/teal/dusk`）× 浅/深色 CSS 变量完全兼容，且**严禁在任何默认占位/示例/截图脚本中使用真实 `grant_secret`**（演示仅允许公开占位值 `playwise-public-demo-secret-0001`）。
     - 离线 Service Worker 与纯客户端 WebCrypto HMAC 发码逻辑保持零后端依赖。
2. **外观主题实景预览（`companion/nro/ui_render_overlay_support.c`）**
   - 主要改造函数：`draw_theme_overlay`（约 L682）。
   - 核心原则：支持「光标悬停预览草稿配色 → 按 A 确认写入 / 按 B 回滚原主题」，右侧实时缩略预览复用主题结构体色板绘制迷你首页主卡、进度条与按钮，零外部位图依赖。
3. **首次设置向导微调（`companion/nro/ui_render_setup.c`）**
   - 主要改造函数：`draw_setup_step1`（L429）、`draw_setup_step2`（L593）、`draw_setup_step3`（L801）、`draw_setup_review`（L260）。
   - 属于低风险收敛打磨：抽取公共顶部 4 步进度轴绘制 helper，统一各步卡片圆角、边距与次级注释字号，不改动向导状态机与存储写入逻辑。
4. **验证方式**
   - Web 前端改动后运行 `python tools/test.py` 覆盖前端单测与离线码向量一致性检查。
   - NRO 改动后运行 `python tools/package_remote.py` 完成 C 编译、UI 测试与 Eden 模拟器测试应用校验。
