04 开发与色彩自查清单 (Engineering Checklist)

在为 Companion NRO 或 Overlay 增加或修改界面时，请逐项比对

✓
双主题适配
所有色彩均使用 palette->xxx 或带有亮暗主题自适应三元判断，无硬编码单一模式颜色。
✓
高可读性明度对比
浅色模式正文字色 ≥ #172640，深色模式正文字色 ≥ #F3F6FD，无昏暗发沉现象。
✓
语义色彩一致性
成功用鲜绿，提醒/休息用暖橙，危险用珊瑚红蔷薇，严禁使用旧版脏沉土黄灰 (#865600)。
✓
动态文本测量
胶囊等同行相邻元素通过 measure_text(...) 动态计算起止位置，杜绝写死 X 偏移。
✓
右侧端对端对齐
列表项与卡片内部右侧数值与说明严格按 card_x + card_w - padding - desc_w 动态右对齐。
✓
焦点交互反馈
当前选中项具备清晰的 2~3px UI_ACCENT / UI_FOCUS 轮廓线与背景反馈。
