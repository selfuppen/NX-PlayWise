## 本批范围与选择方式

本批聚焦「时间计划」下的 3 个健康守护与缓冲页：**护眼休息**、**电视模式规则**、**自主缓冲**，每页提供 A / B 两套 1280×720 主机比例方案（共 6 案）。

评审 HTML 支持浅／深主题、仓库四套风格（石墨／纸墨／雾青／暮霭）、每页 6 个典型业务场景、页面内直接点按体验草稿与影响联动、规则说明弹窗、放大试操作、当前生产代码参考图对照（含路径与 SHA-256）、独立浏览器存储以及选择 JSON／文字导出。

参考图由当前生产绘制代码生成（Host 固定示例数据，非真机硬件抓拍）；A / B 为 1280×720 拟议布局样稿。本批未修改产品源码、未执行构建或部署，定稿实现时再验证三语文本测量、实际手柄焦点与触摸矩形。

## 交互与业务边界

- **护眼休息边界**：使用时长 1–240 分钟（快捷 20/30/40/60 分）、休息时长 1–60 分钟（快捷 5/10/15/20 分）；关闭总开关保留已填时长预设；亮屏累计游玩，休眠不计游玩但持续计入休息倒计时；不扣每日可用额度，不限时日也按实际用量独立累计；`X 跳过本次休息` 仅在休息中可用；首次开启需确认官方家长控制。
- **电视模式规则边界**：三模式保持「不限制 / 仅允许电视大屏 / 允许少量掌机应急（5–1440 分）」；Switch Lite 自动禁用「仅允许电视大屏」；非电视使用双计总额度与非电视限额，用尽接回电视可继续使用总额度余量；`X 今日解除` 需家长 PIN 且仅当日生效、明日恢复；掌机下收紧至立即受限或状态过期／未知时，保留长按确认门禁。
- **自主缓冲边界**：维持协议四档 `{关闭, 5, 10, 15}` 分钟；每天限领 1 次、仅限限时日、领取失败不扣资格；缓冲只增加今日可用额度，不延后就寝、护眼或电视限制；今日已领取后再改档位，次日换日生效，不重置当日资格。
- **状态新鲜度契约**：状态过期或未刷新时保持“待确认”与原 `Y 刷新` 入口，不猜测余额、不按墙钟假扣游玩累计；可继续编辑草稿，危险操作保持长按门禁。

## 选定方案与实现记录（2026-11-22）

已按用户确认的选择落地第四批全部 3 个页面，沿用统一单源布局矩形、触控命中、手柄导航与三语文本边界门禁：

- **护眼休息 -> 方案 A**：左列为总开关卡、游玩（20/30/40/60 分）与休息（5/10/15/20 分）快捷档＋胶囊步进器、3 轮比例节奏条与按需「规则说明」按钮（弹出 4 卡 `PTC_UI_OVERLAY_EYE_CARE_RULES` 模态说明，取代原底栏四列小字墙）；右列展示实时阶段、保存前后对比、休眠与独立判定要点、`X 跳过本次休息`（仅休息中可用）、前置确认与并排「ZL 放弃 / + 保存」。
- **电视模式规则 -> 方案 A**：左列保留三模式图示行并在第三行集成 `15 / 30 / 45 / 60` 分快捷档与 `- / 分钟 / +` 胶囊步进器；右列上部并排展示非电视剩余与今日总剩余双指标卡、保存前后对比及预览／长按提示，下部归位「今日例外」卡（右上角「规则详解」胶囊 + `X 今日解除`）与右列底端「ZL 放弃 / + 保存规则」，释放底栏仅保留统一手柄指引。
- **自主缓冲 -> 方案 A**：由旧 880×480 悬浮弹窗升级为标准三段式全页（保留 `PTC_UI_OVERLAY_AUTONOMY` 入口与回执状态机），提供顶栏状态胶囊、`B 返回` 与 `Y 刷新`；左侧为说明卡、2×2 四档选项卡（区分「生效中／已选」徽标）与 3 条精炼边界芯片，右侧展示今日领取态势、保存前后／明日生效对比、孩子端按钮预览及「ZL 放弃 / + 保存」。
