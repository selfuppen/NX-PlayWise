# 节假日日历数据

PlayWise 的地区节假日规则运行时不联网，也不依据农历或固定算法推算调休。内置中国大陆 2026 年数据依据国务院办公厅正式通知人工整理，经确定性 C 测试和统一 package 门禁校验后编译进规则核心。家长也可[自制并导入其他地区的一年日历](../使用/自制节假日日历格式.md)；用户导入数据不宣称经官方核实。

- 数据版本：`1`
- 覆盖年份：`2026`
- 通知：国务院办公厅关于 2026 年部分节假日安排的通知，国办发明电〔2025〕7 号
- 发布日期：2025-11-04
- 官方来源：https://www.gov.cn/yaowen/liebiao/202511/content_7047099.htm

规则核心同时公开内置日历按年份枚举的节日分组、显示名称、连续放假范围和对应调休工作日；主机 UI 查看已应用地区及年份的日历数据，不维护另一份日期表。当前年份未覆盖时明确显示未覆盖，不把每周计划回退结果冒充节假日数据。

## 更新与回退

内置数据版本随程序发布。用户导入文件的 `format_version` 仅为格式版本，同地区同年可在家长确认后覆盖库索引，不要求内容版本递增。导入不会立即改动已应用的日历或 PCTL；须另行确认应用。运行时按摘要重新校验已应用文件；损坏时报告错误并停止新的控制写入，不改选其他地区。

日历覆盖终点前 30 天开始提示更新。进入未覆盖年份后，国家节假日层停止参与规则选择并回退每周计划；今日额度调整仍保持最高优先级。

当前威胁模型假设儿童无法修改主机日期或直接篡改 SD 卡数据。启用 Nintendo 官方家长控制后，修改 Switch 系统日期和时间需要输入 Nintendo 官方家长控制 PIN；该 PIN 与只保护任我玩家长区的 PlayWise PIN 相互独立。因此首版直接采用主机当前本地日期和时间，不实现独立的系统时间回退检测，也不实现日历包签名。关闭 Nintendo 官方家长控制后的系统时间保护不在本项目承诺范围内。
