## 交互与业务边界

- **家长密码边界**：严格遵守认证常量——1–64 位数字、全程仅掩码显示、错误密码不保留（重试自动清空）、连续 5 次错误触发安全冷却；摇杆 1–8 顺时针 + 十字键同正方向 + `X=0` + `Y=9` + `ZL 退格` + `+ 确认` + `长按 + 切换系统传统键盘`；错误与冷却态始终提供 `X 支持与恢复`（只读查看帮助与导出诊断，修改设置仍需验证 PIN）。
- **输码兑换边界**：8 位码格式化为 `XXXX XXXX`，仅主机当日有效、单次消费；预览清晰呈现代码面额、受 1440 分钟每日上限影响的实际增加值与当前→兑换后余量；正常加时单按确认，触及零余量／转限时／状态未知保留长按 1 秒门禁；等待态明确可安全关闭并续查、切勿重复输码；失败与回滚绝不消耗加时码（不扣 nonce）。
- **签发与配对边界**：本机签发范围 1–1440 分钟，调整草稿时长绝不改变或撤销已生成的旧码，每次签发前均二次验证家长 PIN；二维码无论浅暗主题均保持纯黑模块配纯白底高对比极性；离线单文件流程继续导出 `sdmc:/switch/playwise/parent-import.json` 并提示勿用聊天软件内置预览器、勿转发密钥；公开演示密钥必须显眼警告。
- **额度编辑与分级确认边界**：长按是确认门禁而非“剩余 0 分钟”的通用代名词，文案明确区分“立即受限”与“状态待确认／无法核算余量”；状态过期或未刷新时保持“待确认”与原 `Y` 刷新入口，不猜测余量；今日不限时与快速加时仅影响今日，就寝、护眼与电视规则独立生效。
